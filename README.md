# PCraft | فروشگاه قطعات کامپیوتر + سیستم‌ساز هوشمند

فرانت‌اند مدرن و حرفه‌ای با تمرکز روی **PC Builder** و تشخیص سازگاری قطعات.

## ویژگی‌های کلیدی

- سیستم‌ساز ۸ مرحله‌ای با فیلتر و مرتب‌سازی
- تشخیص هوشمند سازگاری + **امتیاز سازگاری** (۰–۱۰۰)
- برآورد بنچمارک گیمینگ (۱۰۸۰p / ۱۴۴۰p / ۴K)
- نظر هوش مصنوعی PCraft برای هر حالت بیلد
- ذخیره و اشتراک‌گذاری بیلد با لینک
- نوار قیمت ثابت در موبایل
- بیش از ۱۰۰ قطعه واقعی (مادربرد، CPU، GPU، SSD، پاور و ...)
- تم دارک تکنولوژی با کنتراست بالا

## ساختار

```
Myproject/
├── index.html
├── builder.html      ← هسته اصلی
├── product.html
├── cart.html
├── css/styles.css
├── js/

│   ├── builder.js    ← منطق سازگاری، امتیاز، بنچمارک، اشتراک

```

## اجرا

```bash
python -m http.server 8000
# یا
npx serve .
```

سپس `http://localhost:8000` را باز کنید.
